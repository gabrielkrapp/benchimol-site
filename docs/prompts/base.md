## Correções técnicas aprovadas de 02/10/2026

Leia `docs/validation/corrections-2026-10-02/README.md` e os relatórios da área antes de desfazer ou substituir as correções. Preserve a exceção de crawl apenas para mídias públicas, aviso vigente no HTML inicial, metadata/schema coerentes e texto editorial literal. RLS e privilégios explícitos se complementam; não restaurar GRANT ALL para resolver uma falha de API. Novas funções da aplicação em public/private exigem concessão de EXECUTE explícita; a remoção do default global de PUBLIC não apaga defaults explícitos dos schemas geridos.

Uploads geridos novos são decodificados integralmente com limites de bytes/pixels/quadros, preservando bytes e orientação EXIF. Não aceitar assinatura isolada como prova de imagem válida. A limpeza manual de intenções abandonadas usa projeto/hash/plano exatos e nunca é disparada por preview, deploy, cron ou endpoint público. Não apagar mídias registradas ou referenciadas.

Derivados públicos são gerados por `npm run images:public`, sem sobrescrever os originais. Banner WebP lossless e CSS com hash têm cache imutável. Não editar arquivos com hash diretamente, nem remover hashes antigos enquanto abas/servidor puderem referenciá-los. Preserve dimensões, proporção de srcset, prioridade da capa/banner e estabilidade da barra lateral. CSS compacto remove só repetição comprovadamente redundante; não fazer purge por visita à Home. Com dev ativo, rode a suíte direta `node node_modules/vitest/vitest.mjs run` em sequência, sem pretest/geração concorrente.
